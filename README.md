# automation-showcase

A collection of automation workflow examples covering data collection, file processing, reporting, notifications, API integration, approvals, CI/CD, and monitoring.

## Workflows

| Workflow | Description |
|---|---|
| [workflow-1-data-collection](workflow-1-data-collection/) | Collecting data from source systems |
| [workflow-2-file-processing](workflow-2-file-processing/) | Processing and transforming files |
| [workflow-3-report-generation](workflow-3-report-generation/) | Generating reports from processed data |
| [workflow-4-notifications](workflow-4-notifications/) | Sending notifications and alerts |
| [workflow-5-api-integration](workflow-5-api-integration/) | Integrating with external APIs |
| [workflow-6-approval-process](workflow-6-approval-process/) | Routing and tracking approvals |
| [workflow-7-ci-cd](workflow-7-ci-cd/) | Continuous integration and deployment |
| [workflow-8-monitoring](workflow-8-monitoring/) | Monitoring systems and jobs |

See [docs/](docs/) for additional documentation.
